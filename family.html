ESPACIO FAMILIAR COMPARTIDO

La confianza se construye con acuerdos claros.

Un espacio para compartir avances que el estudiante decide publicar, conversar sobre planes y revisar compromisos. No es rastreo ni vigilancia oculta.

1. Conectar ADAZ

Introduce los mismos datos públicos del proyecto Supabase que usas en ADAZ Personal. Como son dos APK independientes, esta configuración se guarda una vez en cada teléfono. Nunca introduzcas una service-role key.

2. Acceso seguro

El acceso funciona igual que en ADAZ Personal: cada integrante recibe un enlace de un solo uso en su propio correo. No necesitas crear ni recordar otra contraseña.

Sesión

Vincular a un padre, madre o acudiente

Escribe el correo del adulto que recibirá la invitación. El código solo funciona para ese correo y vence en 7 días.

Qué compartes

Todo empieza desactivado. Tú eliges las categorías y puedes cambiar o revocar el acceso.

Estadísticas de uso del teléfono

Comparte la aplicación detectada y el tiempo acumulado de Android. Solo se envía si activas el permiso correspondiente.

Publicar resumen de hoy

Solo se envían cifras resumidas. No se suben notas privadas, conversaciones, datos de salud detallados, clientes, importes comerciales ni ubicación.

Plan de salida

Registra manualmente destino, compañía y horario para conversar el permiso. No hay GPS ni seguimiento en segundo plano.

Conexiones activas

Vincular con un código

El estudiante debe generar el código e indicártelo directamente. Tu correo debe coincidir con el que recibió la invitación.

Actividad del teléfono

Actualización cada 15 segundos mientras ADAZ Family está abierto. Se muestra la antigüedad del último dato recibido.

Resumen compartido

Solo aparecerán categorías que el estudiante haya autorizado y publicado.

Uso de aplicaciones · ADAZ Live Usage

Muestra la última aplicación detectada y el tiempo diario compartido desde ADAZ Personal. La hora de captura permite saber si los datos están actualizados.
